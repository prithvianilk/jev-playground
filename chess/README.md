# Jev Chess

A simple one-player chess board. You play White; Jev plays Black by choosing from the legal moves generated by `chess.js`.

Run it from this directory:

```bash
cd chess
OPENROUTER_API_KEY="your-key" go run .
```

Open <http://localhost:8080>. The server keeps the API key private and sends Jev a typed `choice` question whose criteria are the current legal moves. The board state is serialized as rows of `COLOR,PIECE` tokens separated by `|`, with rows separated by newlines.
